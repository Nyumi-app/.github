# Nyumi APP

Nyumi é uma bot de música para Discord com personalidade dark/cute: entra no canal de voz, toca suas faixas e mantém a call fluindo.

## O que a Nyumi faz

- Toca músicas por pesquisa ou link com `/play`
- Gerencia fila com `/queue` e `/skip`
- Mostra a faixa atual com `/nowplaying`
- Para e limpa com `/stop` e sai com `/leave`

## Comandos principais

| Comando       | Ação |
| ------------- | ---- |
| `/play`       | Busca e toca a música solicitada |
| `/skip`       | Pula para a próxima faixa |
| `/stop`       | Para a reprodução e limpa a fila |
| `/queue`      | Mostra as músicas na fila |
| `/nowplaying` | Exibe a música atual |
| `/leave`      | Sai do canal de voz |
